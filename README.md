# ガラガラ！ハイハイレース

「お願い！ そっちじゃないって！！」

ガラガラの位置と鳴らすタイミングで、自由奔放な赤ちゃんをゴールへ誘導する3Dブラウザーゲームです。

**[ブラウザーで遊ぶ](https://cadmium2525.github.io/baby-race/)** · [リポジトリー](https://github.com/cadmium2525/baby-race)

## レース

- 常に赤ちゃん4体が参加。ひとりで遊ぶとCPU3体が相手です。
- 同じ端末で2〜4人対戦。空いている枠はCPUが担当します。
- 制限時間60秒。最初のゴールで勝敗が決まり、時間切れは進行度で順位を判定します。
- ごきげん・キョロキョロ・寄り道・ノリノリ・ひとやすみの基本行動。
- ガラガラは近くで、1秒に1回くらい。連打すると飽きてしまいます。
- 各参加者が1回だけ使えるスーパーガラガラ。CPUも自分のガラガラとスーパーを使います。

モードは「ひとりでレース／みんなでレース」「ハプニング大盛り」「ガチハイハイ」の3種類です。大盛りはイベント多め、ガチでは超レア覚醒が発生しません。妨害の連続発生とゴール直前の長い停止を抑え、最後尾には控えめな速度補正があります。

通常モードの最初のアクシデントは約4〜6秒、最初のレアは約9〜12秒が目安です。レアはレース中に最大3回、超レアは約半数のレースで1回発生する設定です。発生待ちやレースの終了時点によって回数は変わります。大盛りモードではさらに多く発生します。

レア・超レアが発生すると、レース全体を一時停止して対象のベビーへズームします。演出後は元のカメラへ戻り、同じ位置・残り時間・効果時間から再開します。演出は「演出をスキップ」またはEnterで短縮でき、Escの一時停止中は演出も停止します。

## コースとおめかし

タイトルの **準備する** から、人数・コース・ベビーの見た目を変更できます。

| コース | 特徴 |
| --- | --- |
| はじめてのプレイマット | 広いマットで、基本の5種類のゾーンを体験 |
| おもちゃパレード | おもちゃの誘惑とボールが多いコース |
| くもいろクッション | ふわふわの減速をよけて、音の響く道を選ぶコース |

おもちゃは進路を引き寄せ、ボールは横に押し、クッションは減速します。音の響くゾーンでは呼びかけが遠くまで届き、ラストスパートでは加速します。

4体それぞれの名前・服の色・アクセサリーを変更できます。アクセサリーは、くるりん・リボン・ぼうし・おうかん・うさみみの5種類。CPUのベビーも変更できます。

設定・レース数・勝利数・発見したハプニングは、このブラウザーのローカルストレージに保存します。ストレージが使えない場合もレースは遊べます。

## 全24種類のハプニング

| 種類 | 内容 |
| --- | --- |
| 通常8種類 | アヒルさん発見、キョロキョロ、おしりペタン、こっち見て、ガラガラ飽きた、ハイハイ迷子、おててパチパチ、くしゃみ |
| レア8種類 | おしりジェット、ほふくの達人、赤ちゃん渋滞、テンション爆発、つられ笑い、ハイハイ大回転、ミルクの誘惑、急なライバル意識 |
| 超レア8種類 | たっち覚醒、ベビーロボ、ランウェイ・ベビー、ベビー忍者、逆走の王、分身の術、覚醒おしりドリフト、ゴール目前のドヤ顔 |

それぞれ移動・停止・旋回・他のベビーへの影響と、専用アニメーション・合成効果音があります。たっち覚醒はポーズから3秒間の高速走行へ移り、曲がりにくい状態でもガラガラで誘導できます。

発見したイベントは **ハプニングずかん** に記録されます。大盛りモードで新しいハプニングを探してみてください。

## 操作

| プレイヤー | 移動 | 鳴らす | スーパー |
| --- | --- | --- | --- |
| 1P | WASD | Space | R |
| 2P | 矢印キー | Enter | 右Shift |
| 3P | IJKL | O | U |
| 4P | テンキー8456 | テンキー0 | テンキー. |
| ゲームパッド | 左スティック | A | RB |

ひとりのときは矢印キーも1Pに使えます。ゲームパッドは接続順に1P〜4Pへ割り当てます。キーボードの同時押し可能数は機種によって異なるため、多人プレイではゲームパッドも利用できます。

マウスをコース上で移動、またはスマートフォンでドラッグするとガラガラが移動します。クリックや「鳴らす」ボタンで鳴らします。複数人対戦では画面下のプレイヤー選択で、マウス・タッチの操作対象を変更できます。

Escまたは一時停止ボタンで停止・再開。画面からフォーカスが外れても自動で一時停止します。

♪ ボタンは効果音のオン・オフ。♫ ボタンは実況のオン・オフで、実況は最初はオフです。対応端末にインストールされた日本語音声を使います。音声がない端末では効果音とテロップで楽しめます。重要なイベントを優先し、音声が重なりすぎないようにしています。

## 開発と検証

Node.js 22.12以上を使い、リポジトリーのルートで実行します。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザーで開いてください。

```sh
npm test
npm run build
npm run preview
```

- `npm test`：4体のレース・CPU3体の自動誘導・24イベント・5種類のゾーン・勝敗・モード・FPSによらない再現性に加え、ゴール付近の滑らかなカメラ追従と、レア演出の独立した時計・重複抑制・停止と復帰を確認。
- `npm run build`：TypeScriptの型チェックと公開用ビルド。
- `npm run test:browser`：インストール済みのGoogle Chromeで、画面表示・レース・複数人入力・設定保存・スマートフォン表示を確認。

ブラウザーテストでは装飾用のGoogle Fontsを除外し、外部通信の成否に依存せず操作を確認します。スマートフォン表示はブラウザーのエミュレーションです。

Ver.2.1では、レース約29秒でゴールを画面に含める際に画角が一度に変化していた処理を修正し、位置とズームを滑らかに追従させています。イベント用の描画プログラムはレース開始前に準備します。

2026-10-22にロジックテスト62件とブラウザーテスト7件が成功しました。レア演出中の全員の位置・レース時計・効果時間の停止、入力の無効化、手動一時停止、スキップ後の復帰、通常モードの完走・再戦、4人の入力、スマートフォン2サイズを確認しています。

## 公開と構成

`.github/workflows/pages.yml` が、`main`へのpushを契機にテスト・ビルド・GitHub Pagesへの公開を行います。このリポジトリーのPagesはGitHub Actions方式に設定済みです。`dist/`、依存ライブラリー、一時検証ファイルはGitに含めません。

Three.js + TypeScript + Viteで構成しています。ゲームロジックと描画を分け、赤ちゃん・コース・小物はThree.jsの形状、効果音はWeb Audio APIで生成します。ゲームサーバーやAPIキー、外部モデル・画像・音声素材は不要です。

Google Fontsは装飾用に非同期で読み込みます。読み込めない場合は端末の日本語フォントで表示します。対応環境はPC・スマートフォンのWebGL対応ブラウザーです。Nintendo Switch向けネイティブ版やオンライン対戦は含みません。
