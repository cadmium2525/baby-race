# ガラガラ！ハイハイレース

「お願い！ そっちじゃないって！！」

Three.js + TypeScript + Vite で動く、ガラガラで赤ちゃんを誘導するブラウザーゲームの試作です。赤ちゃんを直接操作せず、ガラガラの位置と鳴らすタイミングでゴールへ誘導します。

独立リポジトリー [cadmium2525/baby-race](https://github.com/cadmium2525/baby-race) で管理しています。公開予定 URL は [https://cadmium2525.github.io/baby-race/](https://cadmium2525.github.io/baby-race/) です。公開先での動作確認はまだ完了していません。

## 遊べる範囲

- 1 人 vs CPU、赤ちゃん 2 人、1 コース、制限時間 60 秒。
- ごきげん・キョロキョロ・寄り道・ノリノリ・ひとやすみの基本行動。
- アヒルへの寄り道、おしりペタン、突然立って爆走する「たっち覚醒！」。
- 1 レースに 1 回だけ使えるスーパーガラガラ。
- 最初にゴールした赤ちゃんが勝利。時間切れは進行度で判定。
- 「ふつう」「ハプニング大盛り」「ガチハイハイ」の 3 モード。

初期プレイアブル版の範囲です。4 人対戦、複数コース、Nintendo Switch 向け移植は含みません。スマートフォンはタッチ操作に対応しますが、端末ごとの動作や操作感は調整の対象です。

## 起動と確認

Node.js 22.12 以上を使います。この README があるリポジトリーのルートで実行してください。

```sh
npm ci
npm run dev
```

表示されたローカル URL をブラウザーで開きます。`index.html` を直接開かず、Vite のサーバー経由で起動してください。

```sh
npm test
npm run build
npm run preview
```

`npm test` はゲーム進行ロジックのテスト、`npm run build` は型チェックと公開用ビルドです。`npm run preview` で `dist/` の完成版をローカル確認できます。

Google Chrome がインストール済みの環境では `npm run test:browser` で Playwright の操作・描画確認も実行できます。

前回確認（2026-10-22）では、型チェックと公開ビルド、誘導・飽き・覚醒・勝敗などのルールテスト 13 件、Chrome のデスクトップ／スマートフォン表示の操作テスト 2 件が成功しました。頭上ラベルの重なり修正後はスマートフォン表示を再確認済みです。公開ビルドを `/pages-check/` 配下で配信し、JS エラー・素材の読み込み漏れなくレース開始と操作が動くことも確認しました。スマートフォン表示の確認はブラウザーのエミュレーションです。今回のブラウザーテスト再実行は起動待ちでタイムアウトしたため、操作・描画の再確認は未完了です。

## 操作

| 操作 | 内容 |
| --- | --- |
| マウスをコース上で移動 | ガラガラの位置を移動 |
| コースをクリック / Space | ガラガラを鳴らす |
| 矢印キー / WASD | ガラガラを移動 |
| R / スーパーのボタン | スーパーガラガラを使う |
| ゲームパッドの左スティック / A / RB | ガラガラ移動 / 鳴らす / スーパー |
| Esc / 一時停止のボタン | 一時停止・再開 |
| 音のボタン | 効果音のオン・オフ |
| スマートフォンでコースをドラッグ | ガラガラを移動 |
| スマートフォンの「鳴らす」ボタン | ガラガラを鳴らす |

ガラガラは赤ちゃんの少し前で鳴らすと誘導しやすくなります。連打しすぎると飽きるので、反応を見ながら呼びかけてください。立って走り出した赤ちゃんも誘導できますが、曲がるのが苦手です。

音は最初のボタン操作で有効になります。Web Audio API が使えない環境でもゲームは続行できます。

## GitHub Pages への公開

このリポジトリーから公開するワークフローを、`.github/workflows/pages.yml` に用意しています。控えのテンプレートは `deploy/github-pages.yml.example` にあります。

1. [リポジトリー](https://github.com/cadmium2525/baby-race) の **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
2. `main` ブランチへ push します。別名の既定ブランチを使う場合は、ワークフローの `branches` を変更してください。
3. Actions の成功後、Pages に表示される URL を開きます。

Vite の `base: './'` により、`https://cadmium2525.github.io/baby-race/` 配下でも JS や CSS を相対パスで読み込みます。サーバー、API キー、外部データベースは不要です。

## 技術構成

Three.js の形状から赤ちゃん・ガラガラ・おもちゃ・プレイマットを組み立てています。モデル、画像、音声の外部素材は使っていません。効果音は Web Audio API で生成します。

GitHub Pages には `dist/` だけを配置します。開発時の依存関係は `npm ci` で取得し、ビルド後のゲーム本体には外部アセットの配信サーバーを必要としません。

Google Fonts の丸ゴシックを装飾用に読み込みます。ネットワークが使えないときは端末の日本語フォントで表示します。

導入方法は [Three.js 公式マニュアル](https://threejs.org/manual/pages/installation.html)、Pages のビルド構成は [Vite 公式ガイド](https://vite.dev/guide/static-deploy.html#github-pages) を参照しています。
